**СЕТЕВОЕ ОБОРУДОВАНИЕ**

- «Сетевое оборудование» – широкий спектр устройств, которые служат для создания сетей передачи данных.
- Сетевое оборудование делится на две категории:
    - Активное сетевое оборудование
    - Пассивное сетевое оборудование

### АКТИВНОЕ СЕТЕВОЕ ОБОРУДОВАНИЕ

- Активное сетевое оборудование — любое устройство, проводящее цифровую обработку передаваемого сигнала.
- К активному сетевому оборудованию относят:
    - Коммутаторы (кадры обрабатывает параллельно)
    - Мосты (кадры обрабатывает последовательно)
    - Шлюзы
    - Маршрутизаторы
    - Сетевые адаптеры
    - Принт-серверы
    - Модемы

### КОММУТАТОРЫ
- Коммутатор (свитч, switch) — сетевое устройство, соединяющее узлы компьютерной сети в пределах одного сегмента.
- От концентратора коммутатор отличается тем, что передает данные только непосредственно получателю, а не рассылает их на все доступные сетевые интерфейсы.
- Производительность и безопасность работы сети – повышаются.

### Шлюз
Это устройство или программное обеспечение, которое обеспечивает взаимодействие между компьютерными сетями, использующими разные протоколы передачи данных.  
Существует аппаратный и программный шлюз


### МАРШРУТИЗАТОРЫ

- Маршрутизатор (роутер, router) — сетевое устройство, пересылающее пакеты сетевого уровня из одной подсети в другую по определенным правилам.
- Маршрутизатор определяет путь (маршрут), по которому необходимо передать данные, используя специальную таблицу маршрутизации.
- С помощью маршрутизаторов, сеть можно делить на подсети, увеличив её производительность
- Маршрутизаторы применяют для объединения разнотипных, иногда несовместимых по архитектуре и протоколам сетей.

### СЕТЕВЫЕ АДАПТЕРЫ

- Сетевой адаптер (сетевая карта, сетевая плата) — устройство, через которое компьютер физически подключается к сети.
- Сетевой адаптер и его драйвер реализует работу на физическом и канальном уровнях модели OSI.


Главная задача сетевой карты — обеспечить стабильную передачу данных. Для этого она выполняет три ключевые функции:

- Преобразование данных. Адаптер преобразует цифровые данные из компьютера в сигналы, которые передаются по сетевому кабелю или по воздуху. Затем он выполняет обратное преобразование для входящих данных.
- Обеспечение доступа. Это устройство обеспечивает физическое подключение устройств к локальной сети и интернету через порт (для кабеля) или антенну (для Wi-Fi).
- Уникальная идентификация. У каждой карты есть уникальный MAC-адрес. Это как серийный номер, который не меняется. Он нужен, чтобы другие сетевые устройства в локальной сети точно знали, кому отправлять данные.

### Виды сетевых карт 

- Интегрированный 
- Дискретный 
- Внешние 

### ПАССИВНОЕ СЕТЕВОЕ ОБОРУДОВАНИЕ

- Пассивным сетевым оборудованием называется оборудование, которое не производит цифровой обработки передаваемого через него сигнала.
- К пассивному сетевому оборудованию относят:
    - Концентраторы
    - Кабели
    - Разъемы
    - Коммутационные панели

### КОНЦЕНТРАТОРЫ
- КОНЦЕНТРАТОР (ХАБ, HUB) — СЕТЕВОЕ УСТРОЙСТВО, СЛУЖАЩЕЕ ДЛЯ ОБЪЕДИНЕНИЯ НЕСКОЛЬКИХ КОМПЬЮТЕРОВ, ПОДКЛЮЧЕННЫХ К ENTERNET, В ОБЩИЙ СЕТЕВОЙ СЕГМЕНТ
- Кабели различного типа — одна из разновидностей пассивного сетевого оборудования.
- Кабельная инфраструктура сети — это основа обеспечения нормальной работы сети на долгое время.
- Для построения универсальных локальных телекоммуникационных сетей все используют СКС — структурированные кабельные системы.
